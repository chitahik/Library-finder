# Library Finder V3.4 — 도서관별 대출목록

핵심 기능
1. 책 목록 한꺼번에 입력
2. 오늘 갈 도서관 우선순위
3. 네 도서관 각각에서 '오늘 바로 빌릴 수 있는 책' 목록 확인

UI 변경
- 1순위 도서관은 기본 펼침
- 2~4위 도서관도 접이식 목록으로 바로 확인 가능
- 각 도서관별로 즉시대출 가능 / 소장하지만 현재 불가 / 조회 실패를 구분
- 순위는 복본 수가 아니라 입력한 서로 다른 책 제목 중 즉시대출 가능한 제목 수 기준

성능
- 10권 안팎 검색 시 정독·교육청 계열 공식 조회와 청운 두 곳 브라우저 자동화를 함께 사용하므로
  1~2권 검색보다 느린 것이 정상입니다.
- 일시적 오류를 줄이기 위해 재시도와 요청 간격을 유지합니다.
