# Library Finder V3.5 — 끊겨도 이어받는 안정성 버전

핵심 개선
- 책 10권 검색 중 도서관 하나가 실패해도 전체 검색은 계속 진행
- 제목 × 도서관 단위로 결과를 즉시 체크포인트에 저장
- Streamlit 연결이 잠깐 끊기거나 화면이 다시 연결되어도 같은 책 목록이면 완료된 조회를 불러와 이어서 검색
- 진행상황: 현재 몇 번째 책 / 어떤 도서관 / 전체 몇 개 작업 중인지 표시
- 실패 항목은 '소장 없음'으로 처리하지 않음
- 검색 완료 후 '실패한 항목만 다시 검색' 버튼 제공
- 이미 성공한 결과는 재검색하지 않고 그대로 보존

주의
- Streamlit Community Cloud의 /tmp는 앱 인스턴스가 완전히 재시작되면 지워질 수 있습니다.
- 하지만 일반적인 브라우저 재연결, WebSocket 재연결, 같은 실행 인스턴스 내 rerun에는 도움이 됩니다.
- 완전한 영구 저장이 필요하면 이후 SQLite/외부 DB/캐시 서비스로 확장할 수 있습니다.

기존 기능 유지
- 책 목록 일괄검색
- 오늘 갈 도서관 우선순위
- 네 도서관 각각에서 오늘 빌릴 수 있는 책 목록
- 책별 상세 결과
