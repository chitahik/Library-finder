# Library Finder V3.2 — 10권 안정화

핵심 변경
- 10권 안팎 일괄검색 안정화
- 서울시교육청 공식 검색: 429/5xx/연결 오류 최대 3회 재시도
- 검색 변형 중 일부 요청만 실패한 경우 '소장 없음'을 '조회 오류'로 잘못 표시하던 문제 수정
- 종로구 Playwright 자동검색: 1회 재시도
- 책별 검색 사이 짧은 간격을 두어 공식 사이트에 요청이 몰리지 않게 조정
- '소장 없음'과 '조회 오류'를 명확히 구분
- 최대 15권, 권장 10권 안팎
- 추천/우선 방문 기능은 추가하지 않고 핵심 검색 기능 유지

테스트 기준
- 1권/2권 검색 정상
- 10권 검색 시 전체 결과가 끝까지 표시되어야 함
- 일시적 공식사이트 오류는 자동 재시도 후 표시
