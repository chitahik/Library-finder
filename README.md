
# 우리 동네 도서관 책 찾기

정독도서관, 서울특별시교육청 어린이도서관, 청운문학도서관, 청운효자동 북카페의
책 소장/대출 가능 여부를 한 화면에서 확인하는 소규모 공유용 Streamlit 웹앱입니다.

## 핵심 기능

- 책 제목을 여러 권 한 번에 입력
- 제목을 ISBN 판본으로 자동 매칭
- 네 도서관 소장 여부와 대출 가능 여부 조회
- 어느 도서관에 가면 가장 많은 책을 빌릴 수 있는지 자동 계산
- 중요한 책은 공식 도서관 검색 페이지로 바로 최종 확인

## 데이터 출처

국립중앙도서관 **도서관 정보나루 Open API**를 사용합니다.

주의: 도서관 정보나루의 장서/대출 정보는 수집 주기가 있으므로
도서관 자체 시스템의 순간적인 실시간 상태와 차이가 날 수 있습니다.
따라서 앱은 빠른 1차 선별용으로 쓰고, 꼭 필요한 책은 "공식 확인" 링크에서 출발 직전에 최종 확인하는 구조입니다.

---

## 1. API 인증키 받기

도서관 정보나루(data4library.kr)에 회원가입한 뒤
`데이터 활용 > Open API > 이용신청`에서 인증키를 신청합니다.

인증키는 웹앱 서버에 한 번만 저장하면 됩니다.
앱을 쓰는 다른 학부모는 인증키를 알 필요가 없습니다.

---

## 2. 내 컴퓨터에서 실행

Python 3.10+ 권장.

```bash
pip install -r requirements.txt
```

`.streamlit/secrets.toml` 파일을 만들고:

```toml
DATA4LIBRARY_AUTH_KEY = "여기에_발급받은_키"
```

실행:

```bash
streamlit run app.py
```

브라우저에서 자동으로 열립니다.

---

## 3. Streamlit Community Cloud에 공유용으로 배포

1. GitHub에 이 폴더를 새 저장소로 업로드
2. Streamlit Community Cloud에서 새 앱 생성
3. Main file path를 `app.py`로 지정
4. 앱의 Settings > Secrets에 아래를 넣기

```toml
DATA4LIBRARY_AUTH_KEY = "여기에_발급받은_키"
```

5. Deploy

생성된 URL을 카카오톡으로 4명에게 공유하면 됩니다.
API 키는 사용자 화면에 노출되지 않습니다.

---

## 4. 청운문학/청운효자동 코드가 자동으로 안 잡힐 때

앱은 도서관 정보나루의 서울 도서관 목록에서 이름 유사도로 코드를 자동 탐색합니다.
만약 정보나루에 도서관 이름이 다르게 등록돼 탐색에 실패하면,
`TARGET_LIBRARIES`의 해당 항목 `known_code`에 도서관 코드를 넣으면 됩니다.

정독도서관과 어린이도서관 코드는 이미 아래처럼 고정되어 있습니다.

- 정독도서관: `111020`
- 어린이도서관: `111017`

## 향후 V2 추천

첫 버전을 며칠 써보고 정확도가 괜찮으면 다음 기능을 붙이는 것이 좋습니다.

1. 독서목록 사진 업로드 → 책 제목 자동 추출
2. 원하는 판본을 직접 선택하는 UI
3. "대출 가능만 보기"
4. 두 도서관 조합으로 가장 많은 책을 확보하는 경로 계산
5. 공식 도서관 사이트 실시간 조회 어댑터 추가

특히 5번을 추가하면 정보나루의 수집 시차를 보완할 수 있습니다.
