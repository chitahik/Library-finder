# Library Finder V3.3 — 핵심 3기능

이번 버전의 핵심은 딱 세 가지입니다.

1. 책 목록 한꺼번에 입력
   - 한 줄에 한 권
   - 권장 10권 안팎

2. 오늘 어디로 가는 게 가장 나은지 우선순위
   - '복본 수'가 아니라 입력한 서로 다른 제목 중 오늘 즉시대출 가능한 제목 수로 순위 계산
   - 동률이면 확인된 소장 제목 수가 많은 도서관 우선
   - 조회 실패는 0권으로 간주하지 않음

3. 선택한 도서관에서 오늘 빌릴 수 있는 책을 한 번에 목록으로 확인
   - 즉시대출 가능
   - 소장은 있지만 지금 못 빌림
   - 소장 없음
   - 조회 실패
   를 구분해서 표시

기존 V3.2의 10권 안정화 로직, 재시도, 요청 간격, 정독/어린이 공식 조회, 청운 두 곳 브라우저 자동화는 그대로 유지합니다.
