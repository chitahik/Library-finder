# Library Finder V2.5

종로구 자동조회 재도전 버전.

핵심 변경:
- 종로구 검색 파라미터를 추측해서 하드코딩하지 않음
- 종로구 검색 페이지의 실제 form을 읽어 검색어 input 이름과 도서관 checkbox/select 값을 런타임에 자동 탐지
- form method가 GET이든 POST든 실제 method를 따라 제출
- 청운문학도서관 / 청운효자동 북카페 결과를 공식 검색 HTML에서 판정

회귀 테스트:
- 《목화씨》 조혜란 → 청운문학도서관 소장, 대출가능(비치중)
- 청운효자동 북카페 → 같은 검색에서 소장 없음으로 확인된 경우 없음 표시
