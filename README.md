# Library Finder V2.4

정확도 우선 수정판.

- 정독도서관: 자동 조회
- 교육청 어린이도서관: 자동 조회
- 청운문학도서관: 종로구 공식 검색 연결
- 청운효자동 북카페: 종로구 공식 검색 연결

V2.3에서 종로구 공식 검색 페이지를 단순 GET query로 호출해 '소장 없음'으로 오판하던 문제를 제거했습니다.
종로구 공식 검색은 브라우저 폼의 도서관 선택값/세션 상태를 함께 사용하므로,
정확한 요청 규격을 확인하기 전까지는 존재하지 않는 자동 결과를 만들지 않습니다.

회귀 테스트:
- 목화씨 / 조혜란: 청운문학도서관에 실제 소장 및 대출가능(비치중) 확인.
